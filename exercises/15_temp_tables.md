# 演習 15 — 一時テーブルとテーブル変数

対象解説: [docs/15_temp_tables.md](../docs/15_temp_tables.md)
使用DB: `SalesLearning`(先頭で `USE SalesLearning;` を実行しておくこと)

各問、**まず自力でクエリを書いて実行** → 結果を確認 → 解答例
[solutions/15_temp_tables.sql](solutions/15_temp_tables.sql) と照合しましょう。
解答例と書き方が違っても、同じ結果になっていれば正解です。

> ⚠️ **この演習のルール**
> - 一時テーブルを作る問題は、**必ず先頭で `DROP TABLE IF EXISTS #t;`**、
>   **最後にも `DROP TABLE IF EXISTS #t;`** を書くこと(後片付けまでが解答です)。
> - テーブル変数(`DECLARE @t TABLE ...`)を使う問題は、宣言から利用までを
>   **`GO` を挟まない同一バッチ**で書くこと(`GO` をまたぐと変数が消えます)。
> - 本物のテーブル(`Employees` / `Products` など)は **一切変更しないこと**。
>   この演習はすべて読み取り + 一時オブジェクトだけで完結します。

> ⚠️ **Q8・Q9・Q11 は `dbo.OrdersBig`(100万行)を使います。**
> まだ作っていない場合は先に `sample-db/03_bulk_data.sql` を実行してください。

---

## 基礎

**Q1.** `SELECT ... INTO` を使って、一時テーブル `#EmpList` を作りなさい。
列は `EmployeeId` / 氏名(`LastName + N' ' + FirstName`)/ `DepartmentName` / `Salary` の4つ。
部署が未設定の社員(`DepartmentId IS NULL`)も残るように結合すること。
作成後に全件を `SELECT` して 13 行あることを確認し、最後に後片付けまで書くこと。

**Q2.** 今度は `CREATE TABLE` + `INSERT ... SELECT` で、一時テーブル `#ProductSales` を作りなさい。
列と型は `ProductId INT`(主キー)/ `ProductName NVARCHAR(100)` / `合計数量 INT` /
`売上合計 DECIMAL(18,2)`。中身は `OrderDetails` を商品ごとに集計したもの
(売上は `Quantity * UnitPrice * (1 - Discount)` の合計)。
売上合計の高い順に上位 5 件を表示し、後片付けまで書くこと。
(ヒント: 型を自分で決められるのが `CREATE TABLE` 版の利点)

**Q3.** テーブル変数 `@Cat` を宣言して `dbo.Categories` の全行(`CategoryId`, `CategoryName`)を
入れなさい。そのうえで `@Cat` と `dbo.Products` を結合し、**カテゴリ別の商品数と平均単価** を
商品数の多い順に表示しなさい。商品が 0 件のカテゴリも表示すること。
宣言から `SELECT` までを `GO` を挟まずに書くこと。

**Q4.** **ロールバックの違いを体感する。** 一時テーブル `#Memo(内容 NVARCHAR(50))` と
テーブル変数 `@Memo(内容 NVARCHAR(50))` の両方を用意し、`BEGIN TRAN` の中で
それぞれに 1 行ずつ `INSERT` してから `ROLLBACK` しなさい。
その後、両方の中身を `SELECT` して結果を比べ、**なぜ差が出るのか**を 1〜2 行で説明しなさい。

## 応用

**Q5.** **インデックスを後から張れるかの違い。**
(1) `dbo.Orders` から `OrderDate >= '2023-07-01'` の注文を `#Recent` に落とし、
`CustomerId` に非クラスタ化インデックス `IX_Recent_CustomerId` を **後から** 作成しなさい。
(2) 同じ内容をテーブル変数 `@Recent` でやろうとして `CREATE INDEX` を書くと
どうなるか確認し(エラー内容をコメントで説明)、**宣言時のインライン索引構文**
(SQL Server 2014+)で同じ索引を持つように書き直しなさい。
最後に `#Recent` を後片付けすること。

**Q6.** **CTE の複数回参照を一時テーブルに置き換える。**
「顧客別の売上合計」を求め、**その全体平均を上回る顧客だけ**を売上降順で表示したい。
(1) まず CTE を **2 回参照** する形(平均を出すのに 1 回、絞り込むのに 1 回)で書きなさい。
(2) 次に、同じ結果を **一時テーブル `#CustSales` に 1 回だけ落としてから** 2 回参照する形で
書き直しなさい。後片付けまで書くこと。
(3) 実行プランを見て、(1) では顧客別集計が何か所に現れるかを確認しなさい。

**Q7.** **`SELECT INTO` の落とし穴を確認する。**
`SELECT * INTO #EmpCopy FROM dbo.Employees;` で一時テーブルを作り、
`tempdb.sys.columns` を使って `#EmpCopy` の **列名・データ型・NULL 許容** を一覧しなさい
(ヒント: `OBJECT_ID('tempdb..#EmpCopy')` と `tempdb.sys.types` を結合する)。
そのうえで、**元テーブルにあった主キー制約が引き継がれていない**ことを
`tempdb.sys.indexes` などで確認し、`EmployeeId` に主キーを後から追加しなさい。
後片付けまで書くこと。

**Q8.** **一時テーブルに落とす効果を論理読み取りで測る。**(`dbo.OrdersBig` を使用)
`SET STATISTICS IO ON` を有効にしたうえで、
(1) `dbo.OrdersBig` の 2024 年分に対して「顧客別合計」と「担当社員別合計」の
**2 本の集計クエリを直接** 実行しなさい。
(2) 同じ 2024 年分を一時テーブル `#Orders2024` に **1 回だけ** 落としてから、
同じ 2 本の集計を `#Orders2024` に対して実行しなさい。
メッセージタブの **論理読み取り数** を (1) と (2) で比較し、気づいたことをコメントで書きなさい。
最後に後片付けと `SET STATISTICS IO OFF` を忘れないこと。

## チャレンジ

**Q9.** **統計情報の有無が推定行数をどう変えるか。**(`dbo.OrdersBig` を使用)
2024 年分(約 10 万行)を、テーブル変数 `@T` と一時テーブル `#T` の両方に投入し、
それぞれ `dbo.Customers` と結合するクエリを **実際の実行プランを含めて** 実行しなさい。
- `@T` 側と `#T` 側で、スキャン演算子の **推定行数** と **実際の行数** を比べなさい。
- `@T` 側のクエリに `OPTION (RECOMPILE)` を付けると推定行数がどう変わるか確認しなさい。
- 自分の環境の互換性レベルを `sys.databases` で調べ、
  **150 以上なら遅延コンパイルが効いている**ことを確認しなさい。
観察結果をコメントで説明し、後片付けまで書くこと。

**Q10.** **グローバル一時テーブルのスコープ。**
セッション A(いま使っているクエリウィンドウ)で `##SharedList` を作り、`dbo.Departments` を
入れなさい。次に **別のクエリウィンドウ(セッション B)** を開き、
- `SELECT * FROM ##SharedList;` が **成功する**こと
- `SELECT * FROM #EmpList;`(セッション A で作ったローカル一時テーブル)が **失敗する**こと

を確認しなさい。確認後、セッション A で `##SharedList` を明示的に `DROP` すること。
「実務でグローバル一時テーブルをあまり使わない理由」も 1〜2 行で書きなさい。

**Q11.** **段階的に一時テーブルへ落とす実務パターン。**(`dbo.OrdersBig` を使用)
「**2024 年の `Status = N'完了'` の注文について、顧客別 × 担当社員別の売上合計 上位 10 件**」を、
次の 3 段に分けて求めなさい。各段で一時テーブルを作り、結合キーにインデックスを張ること。
- 【段①】`#対象` … 2024 年かつ完了の注文(`OrderId`, `CustomerId`, `EmployeeId`, `Amount`)
- 【段②】`#集計` … `#対象` を `CustomerId` × `EmployeeId` で集計(件数・売上合計)
- 【段③】`#集計` に `Customers` / `Employees` を結合して顧客名・担当者名を付け、上位 10 件を表示

最後に、作成した一時テーブルをすべて `DROP TABLE IF EXISTS` で後片付けしなさい。
また、「この処理を CTE 1 本で書くのと比べた利点」を 2 つコメントで挙げなさい。
