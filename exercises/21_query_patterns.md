# 演習 21 — 実務頻出クエリパターン集

対象解説: [docs/21_query_patterns.md](../docs/21_query_patterns.md)
使用DB: `SalesLearning`(先頭で `USE SalesLearning;` を実行しておくこと)

各問、**まず自力でクエリを書いて実行** → 結果を確認 → 解答例
[solutions/21_query_patterns.sql](solutions/21_query_patterns.sql) と照合しましょう。
解答例と書き方が違っても、同じ結果になっていれば正解です。

> ⚠️ **データを変更する問題(Q5・Q11)では、必ず一時テーブル(`#名前`)のコピーを操作するか、
> `BEGIN TRAN … ROLLBACK` で囲むこと。** `dbo.` のテーブルを直接書き換えてはいけません。
> 使い終わった一時テーブルは `DROP TABLE IF EXISTS #名前;` で必ず後片付けしましょう。

## 基礎

**Q1.** 顧客ごとの **最新の注文**(注文日が最も新しい 1 件)を、
`CustomerId` / `CustomerName` / `OrderId` / `OrderDate` の 4 列で一覧しなさい。
**注文が 1 件も無い顧客(11 ラムダソフト)も、注文列が NULL の行として残す** こと。
(ヒント: `OUTER APPLY` + `TOP (1)`。同じ日に複数注文がある場合に備えてタイブレークを入れる)

**Q2.** カテゴリごとに、**単価の高い商品トップ2** を
`CategoryName` / `ProductName` / `UnitPrice` / 順位 の 4 列で出しなさい。
カテゴリ未設定(`CategoryId IS NULL`)の商品は除外すること。
(ヒント: `ROW_NUMBER()` を CTE に入れてから絞り込む)

**Q3.** 注文ごとに、**含まれる商品名をカンマ区切りで 1 つの列** にまとめなさい。
出力は `OrderId` / `OrderDate` / 商品一覧 / 明細件数 の 4 列。
商品一覧は商品名の昇順に並べること。
(ヒント: `STRING_AGG` は SQL Server 2017 以降。並び順は `WITHIN GROUP` で指定する)

**Q4.** **顧客3(ガンマ物産)** の 2023年 の月次売上を、
**注文の無い月も売上 0 として、2023年1月〜12月の 12 行すべて** 表示しなさい。
(ヒント: 番号表でカレンダー(月初日の一覧)を作り、集計結果を `LEFT JOIN` する。
`NULL` は `ISNULL` で 0 にする)

---

## 応用

**Q5.** 「同じ顧客が二重登録されている」状況を再現し、重複を削除しなさい。

1. `dbo.Customers` を一時テーブル `#Customers` にコピーする。
2. `#Customers` に、既存の顧客と **同じ `CustomerName` + `City`** を持つ行を 3 件追加する
   (`CustomerId` は 101・102・103 など、既存とかぶらない値にする)。
3. `CustomerName` + `City` が重複しているグループを **件数付きで検出** する。
4. 各グループで **`CustomerId` が最小の 1 件だけを残して** 削除する。
5. 削除前後の件数を確認し、一時テーブルを削除する。

(ヒント: `ROW_NUMBER()` を計算する CTE を作り、その CTE に対して `DELETE` する)

**Q6.** 伝票番号の **欠番** を検出しなさい。
`dbo.Orders` の `OrderId` から `1002`・`1003`・`1010`・`1011`・`1012` を除いたものを
一時テーブル `#伝票` に入れ、「欠番の開始番号 / 終了番号 / 欠番件数」を一覧しなさい。
(ヒント: `LEAD` で次の番号を取り、差が 1 より大きい場所を探す)

**Q7.** 顧客ごとに、**注文があった月の連続区間**(継続取引期間)を求めなさい。
出力は `CustomerId` / `CustomerName` / 開始月 / 終了月 / 連続月数。
連続月数が 2 以上の区間だけを表示すること。
(ヒント: 月を `DATEDIFF(MONTH, 基準日, 月)` で整数に直し、そこから顧客内の行番号を引く)

**Q8.** 全社の月次売上について、次の 5 列を 1 つのクエリで出しなさい。
月 / 月売上 / 年累計(**年が変わったらリセット**)/ 3か月移動平均 / 前年同月比(%)。
前年同月比は **欠測月があってもずれない書き方** にすること。
(ヒント: 累計は `ROWS` を明示する。前年同月は `DATEADD(YEAR, -1, 月)` で自己結合。
0 除算対策も忘れずに)

**Q9.** 2023年の **地域(`Region`)別 × 四半期** の売上サマリを、条件付き集計で作りなさい。
列は 地域 / Q1 / Q2 / Q3 / Q4 / 年間合計 / 注文件数。
`PIVOT` 演算子は使わず、`CASE` 式 + 集約で書くこと。
(ヒント: 注文件数は明細を結合しているので `COUNT(DISTINCT OrderId)`)

## チャレンジ

**Q10.** Q3 と同じ「注文ごとの商品名カンマ区切り」を、
**SQL Server 2016 以前でも動く書き方**(`FOR XML PATH` + `STUFF`)で書きなさい。
さらに、`N'ノートPC,本棚,SQL実践ガイド'` という文字列を `STRING_SPLIT` で行に分解し、
`dbo.Products` と結合して商品情報を取り出しなさい。
(ヒント: `FOR XML PATH(N''), TYPE` と `.value(N'.', N'NVARCHAR(MAX)')` はセットで使う。
`STUFF` の第3引数は区切り文字の長さ)

**Q11.** 次のカーソル処理と **同じ結果になる 1 文の `UPDATE`** を書きなさい。

> 作業テーブル `#商品集計`(`dbo.Products` のコピーに「販売数量合計」「販売回数」「販売区分」列を追加)
> の各行について、`dbo.OrderDetails` を集計して
> 販売数量合計・販売回数を埋め、販売数量合計が 50 以上なら `N'主力'`、
> 1 以上 50 未満なら `N'一般'`、0 なら `N'未販売'` を販売区分に入れる。

一時テーブルの作成 → 集合ベースの `UPDATE` → 結果確認 → 後片付け まで書くこと。
(ヒント: `LEFT JOIN` した派生表と `UPDATE t SET … FROM #商品集計 AS t LEFT JOIN (…)` の形)

**Q12.** 2023年について、**注文が 1 件も無かった日の連続期間** を求めなさい。
出力は 開始日 / 終了日 / 日数。日数が 10 日以上の期間だけを表示すること。
(ヒント: 番号表で 2023-01-01〜2023-12-31 の全日付カレンダーを作り、
`NOT EXISTS` で注文の無い日を絞り、そこにアイランドの手法を適用する。
日付は `DATEADD(DAY, -行番号, 日付)` で塊キーにできる)
